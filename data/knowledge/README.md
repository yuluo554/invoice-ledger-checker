# data/knowledge/ 法规知识库

入库纪律（plan/05 §1.4）：

- 每条目格式：`{id, article_no, quote（条文摘录）, relevance（对应规则/设计点）}`，文件级挂 `verification`（渠道 + status + 核对日期 + 查证方法）；
- **无出处不得以确定语气落库**：原文未逐字核对的条目一律 `status: 待核对`，quote 以"（要点）"前缀标识；查证失败的渠道如实登记，不空转；
- 检测规则的"依据"字段只挂本目录三部法规 + 票面自洽逻辑（plan/04 §3），不引申无关条文；
- 搜索通道污染防线：搜索摘要不作为核对依据，只采信可直连官方页面的原文（gov.cn / *.chinatax.gov.cn / 部委政策库）。
